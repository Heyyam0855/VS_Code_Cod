# VS_Code_Cod

A collection of TensorFlow and PyTorch AI Machine Learning examples and tutorials.

## Overview

This repository contains practical examples demonstrating various AI and machine learning concepts using both TensorFlow and PyTorch frameworks.

## Features

- **TensorFlow Examples**: Neural network implementations using TensorFlow
- **PyTorch Examples**: Deep learning models using PyTorch
- **Comparison**: Side-by-side examples showing the same concepts in both frameworks

## Installation

### Prerequisites
- Python 3.8 or higher
- pip package manager

### Setup

1. Clone the repository:
```bash
git clone https://github.com/Heyyam0855/VS_Code_Cod.git
cd VS_Code_Cod
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

## Examples

### TensorFlow Example
Run the TensorFlow example:
```bash
python tensorflow_example.py
```

### PyTorch Example
Run the PyTorch example:
```bash
python pytorch_example.py
```
